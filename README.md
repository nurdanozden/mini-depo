# 📦 Mini Depo Yönetim Sistemi (Warehouse Management System)
Konsol tabanlı Java uygulaması ile temel depo işlemlerini yönetin!  
Bu proje, küçük ve orta ölçekli işletmeler için stok takibi, ürün ekleme, güncelleme ve silme gibi temel işlevleri sağlamaktadır.

---

# Özellikler
✅ **Ürün Ekleme** – Depoya yeni ürün ekleyebilirsiniz.  
✅ **Ürün Listeleme** – Depodaki tüm ürünleri görüntüleyebilirsiniz.  
✅ **Ürün Güncelleme** – Mevcut bir ürünün miktarını veya fiyatını değiştirebilirsiniz.  
✅ **Ürün Silme** – İstediğiniz ürünü depodan kaldırabilirsiniz.  
✅ **Basit ve Kullanıcı Dostu** – Konsol tabanlı, kolay anlaşılır arayüz.

---

# Kullanılan Teknolojiler
- Java 17
- OOP prensipleri
- ArrayList veri yapısı
- IntelliJ IDEA geliştirme ortamı

---

# 📂 Proje Dosya Yapısı
Main.java → Programın başlangıç noktası, menü yönetimi
Product.java → Ürün bilgilerini tutan sınıf
Warehouse.java → Depo işlemlerini yöneten sınıf
